# 🇧🇷 Kaggle Olist Brazilian E-Commerce Analytics

A comprehensive data analysis and processing project conducted in Jupyter Notebooks using **Apache Spark (PySpark)** on a GCP cluster. This project explores the large-scale Olist e-commerce dataset (99,441 orders) across 5 distinct modules to uncover business metrics, handle data transformation challenges, and apply Spark optimization techniques.
